02 / what gets better

优势不是“自动化更多”，而是证据链更短、责任边界更清楚。

把生成、重构和验收拆开后，每个质量问题都有归属：是内容错、母版错、路由错，还是 Office 渲染错。

A / 01⌁

来源与数字可追溯

事实不再靠 OCR 或模型“猜”。source → evidence → whitelist 形成可回查的链，错误更容易定位。

A / 02✦

视觉母版先被证明

先验证完整页面的视觉意图，再进入 PPTX。避免一边生成、一边用代码补成模板。

A / 03◫

编辑性分层而非虚假全矢量

文字、几何、线稿、复杂艺术各走合适路线，明确写出 native / SVG / raster / background。

A / 04!

Fail-closed 的质量门禁

缺 ImageGen provenance、Office 导出或全尺寸审查时，状态是 blocked，不会被 ZIP 有效性掩盖。

A / 05↻

局部修复，避免全 deck 回归

弱页只生成新 round 并合并指定 slide ID，已验收页面和 hash 保持不动。

A / 06⌘

每次迭代都能沉淀

失败、根因、修复和证据写进 improvement ledger，下一次生成先读历史，而不是重复踩坑。

04 / vectorization boundary

不追求全矢量，追求可解释。

重构的单位是“语义对象”。什么应该能改、什么应该保持完整、什么只能作为背景，都在路由表里说清楚。

full-page trace
= native text + native shape + bounded SVG + movable raster + 1 continuous background
对象推荐路线边界与证据
标题 / 正文 / 表格文字NATIVE TEXT

100% 正常文字走原生文本；用 XML / exact-text 审计确认没有替代字符。

卡片 / 分隔线 / 箭头 / 节点NATIVE SHAPE

可测量的简单几何原生化；隐藏前景后，背景不能留下重复边框。

孤立的扁平线稿SVG CANDIDATE

只在路径简单且 PowerPoint render 通过时接受；否则保留 fallback。

照片 / 插画 / UI / 密集图表MOVABLE IMAGE

以有边界、可移动的透明 PNG 保真；明确记录 source_bbox 和拒绝矢量原因。

纸张纹理 / 网格 / ambient fieldCONTINUOUS BG

允许每页一张连续非语义背景；禁止 3×4 等 tile，也禁止语义全页捷径。

05 / gold release

证明齐了，才叫完成。

最终交付不是一个能打开的 .pptx，而是一组能解释“它为什么可信”的证据：来源、母版、对象、渲染、审查和版本。

当前 thesis-defense round 已通过：11 页、176 个原生文本框、273 个“已审核计划”几何对象，最终 PPTX 审计为 298 个原生形状（含 25 个原生图标轮廓）；28 个复杂科学/场景元素保留为有界可移动图片。逐字匹配、PowerPoint 渲染、溢出、图层契约和逐页视觉审查均为 pass。若后续证据缺失，状态仍应回落为 blocked，不能用 ZIP 有效或一张预览图推断 Gold。
