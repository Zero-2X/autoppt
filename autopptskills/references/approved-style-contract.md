# 用户确认的科研 PPT 风格契约（2026-09-20）

适用于本工作流及个人 AutoPPT skill 的后续图片生成、重构和验收。
本契约优先于旧 profile 的稀疏排版、橙色强调和装饰性建议；后续用户明确指定的项目风格可覆盖相应默认项。

## 内容规划：充实的图文论证

每页都应承担足够的信息任务，默认采用中高信息密度。内容页围绕一个结论，提供有来源的论据、方法条件、关键结果及解释；有图时须配对应文字，说明对象、关系和意义。单张大图配几个词、孤立口号、重复空卡片均不合格。

密度来自有效信息和清楚的组织，不来自小字、重复、编造数据或堆满边框。先把完整支撑点写入审核后的 exact_text，再生成图片；不在 prompt 或 manifest 中静默截断。不设机械字数下限，封面、过渡和结尾也应包含其角色所需的具体内容，不能仅因位于首尾就自动稀疏化。资料不足时回到内容规划，不能让 ImageGen 自行补事实。

## 整套视觉：淡色、深字、红色强调

默认白色或淡灰、淡蓝灰底，黑色、深灰或深蓝文字；红色用于关键结论、关键数值、对比变化和需要提醒的内容，少量、稳定使用。示例：背景 #FFFFFF/#F7F8FA，正文 #20242B，结构 #294F68，强调 #B4232D。科学图像和数据编码保留必要原色，不强制改成红蓝色。

保持统一标题区、对齐、字号层级、线宽和间距；由证据选择流程、对比、机制、结果或结构布局，避免连续重复卡片墙。用主体图、解释文本、直接注释和精确排版形成完整画面。深色与 intentional-minimal profile 保留，但只在用户明确选择时使用，不能因主题或修复困难自动切换。

## 参考体系：保留国自然及高校答辩经验

保留现有官方来源登记与参考原型，提取问题—依据—方法—结果/可行性—贡献的叙事、学术层级、图文密度和章节节奏。高校真实毕业答辩样本、学校通用模板、学术设计指南、国自然申请规定应分别标明来源类型；通用模板和申请规定不能宣称为实际答辩样本。采用已核验的视觉资料，不把访问受阻的页面当作已看过的设计。参考内容不自动授权借用校徽、身份或原课题数据。

## ImageGen 每页公共提示词

> 生成一张完整的科研汇报/毕业答辩 PPT 页面。按本页审核内容组织充实的图文论证，默认中高信息密度：主体图与解释文字互相对应，清楚呈现研究对象、关键关系、证据和结论。使用全部必要的已审核文字，逐字保持术语、数字、单位与公式；不自行补充事实，不把完整论证压缩为几个标签。通过清晰分组、直接注释、准确对齐和有层级的字号承载信息，保持投影可读性。
>
> 默认采用淡色背景、黑色或深色正文，红色作少量重点强调。借鉴已核验的国自然汇报及高校学术答辩的严谨结构与成熟排版。整齐、美观、内容丰富，背景与框图保持克制。普通文字使用稳定的无衬线字形和实色，不使用发光、立体、变形、纹理字；文字所在区域干净平整。简单框、线、箭头、节点使用清楚、可测量的几何和适度线宽，避免复杂透明叠加、装饰渐变、阴影缠绕和文字跨越繁杂纹理。
>
> 在生成阶段考虑后续 PowerPoint 重构：明确分离普通文字、简单几何和复杂科学图像。保留科学图像的完整细节与科研含义，使其可作为有界局部图片；不为方便矢量化删减科研内容或降低视觉完成度。当前输出仍须是完整 ImageGen 页面，不能生成空背景等待代码补字。

若用户明确选择其他风格，只覆盖其指定的视觉项，保留信息完整性、内容真值、可编辑分层与保真要求。

## 重构提示词：冻结母版，复现视觉

> 以本页已验收、hash 已冻结的 ImageGen 图为唯一视觉基准进行语义重构。普通文字必须为可见原生文本框，简单形状为原生形状/连接线；复杂科学图像保留为边界明确的局部图片。逐项复现文字内容、字重、字号、换行、字距、位置、尺寸、颜色、红色强调、线宽、裁切、图层顺序与背景。不得重新设计、主动美化、删减内容或移动构图。前景移开后背景不得有残字、重复边框、补丁或轮廓。
>
> SVG 或原生重建损害复杂科学图像时，使用保真局部图片并记录原因；普通文字和简单形状仍须原生可编辑。不得以整页截图、透明文字或隐藏对象制造可编辑假象。不能为提高矢量数量损伤科研表达。

## 验收与修复

母版先审查图文信息充分性、淡底深字红强调、排版完成度与可分离性。乱码时修正分组、断行、区域尺寸并重生成受影响页面；确需调整文字须返回内容规划同步白名单，禁止退化为“标题加三个标签”。

用 Microsoft PowerPoint 导出最终文件，以相同画布/分辨率逐页对照冻结母版，保留并排、叠加、差异图及审查记录。新 Gold 发布的 design-quality 审查须包含 `information_density`、`restrained_style`、`master_visual_fidelity`。检查整个页面和局部细节，任何可见的换行、位置、字体外观、色彩、线条、裁切或残影差异都不得通过。技术指标只辅助定位，不能用平均相似度掩盖局部缺陷。

“一模一样”是必须用最终渲染证明的视觉目标，不是生成前可以保证的能力。原生文本与栅格母版可能存在字体/抗锯齿差异；无法同时满足视觉一致和真实可编辑时，继续修复或报告 blocked，并指出具体差异，不能自行降低标准、换母版掩盖差异或宣称逐像素一致。只有实际比较证明才能描述像素相等。
